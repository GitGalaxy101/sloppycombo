An early native prototype of a Cyber City inspired arcade side room. It runs separately from Deltarune and its save, reading Kris sprites from your Chapter 2 copy and the real Stereo Madness cube opening and music from your Geometry Dash copy.

Clearing the pixel-rendered cube trial unlocks the Quartermaster, with FIGHT, ACT, dodging, and SPARE. Includes retries, pause, fullscreen, and persistent progress. This version covers the supported opening cube section, with approximate GD physics.

Download **DeltaDash-v0.1.0-dev-windows.zip** from Assets below. Extract the whole ZIP, then open **DeltaDash/launch.cmd**. Requires Windows 10/11 x64 and both installed games, including Deltarune Chapter 2 content. Steam installations are detected automatically. Python and the runtime libraries are bundled; no original game files are distributed or modified.

197 tests passed using synthetic content. The Windows executable and actual retail game versions remain unverified; this prerelease is for testing with your installed copies.
